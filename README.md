# Project 1: Data Cleaning and Preparation

## Overview
This project focuses on cleaning and preparing a raw  dataset for analysis.

## Dataset
The dataset contains 14 columns, including Order ID, Date, Customer ID, Product, Quantity, Unit Price, Shipping Address, Payment Method, Order Status, Tracking Number, Item In Cart, Coupon Code, Referral Source, and Total Price.

## Tasks
- Identify missing or null values.
- Remove duplicate records.
- Correct data formats (dates, numbers, and text).
